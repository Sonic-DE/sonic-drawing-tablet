# Sonic Drawing Tablet Release Notes

Sonic Drawing Tablet lets you set up and fine-tune drawing tablets and pens in SonicDE.

## Unreleased

- The tablet detection helper now shows up on the SonicDE desktop.
- The settings module is now called Drawing Tablet.

- Behind the scenes: version update and refreshed dependency versions.

## 6.7.5 (2026-09-12)

- Behind the scenes: added automated tests for the tablet list and updated the version.

## 6.7.4 (2026-08-04)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.
